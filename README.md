# DocFlow ARQ — página de vendas

Página de vendas oficial do DocFlow ARQ, separada da landing page de captação.

## Estrutura

- `index.html` — página pública
- `vendas.css` — estilos e responsividade
- `vendas.js` — interações, checkout e validação de aluno
- `vendas-videos.js` — catálogo de demonstrações
- `vendas-i18n.js` — traduções para português, inglês e espanhol
- `media/` — imagens, ícones e vídeos utilizados

## Publicação

Projeto estático sem etapa de build. Na Vercel, use o diretório raiz e deixe os comandos de build e instalação vazios.
